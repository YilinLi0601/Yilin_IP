# Affect Regulatory Function of Suicidal Ideation via Contrast Avoidance Effect Among Adolescents
This is the repository of supplementary materials for this project

## Project Overview
This project examines the temporal association between suicidal ideation, affective dynamics, and daily events among adolescents using ecological momentary assessment (EMA).

## Repository Contents

1. scripts  
R scripts for data cleaning, descriptive analyses, and visualisation.

2. mplus_models  
Dynamic Structural Equation Models (DSEM) specifications and results.

3. poster_materials  
Full reference list
